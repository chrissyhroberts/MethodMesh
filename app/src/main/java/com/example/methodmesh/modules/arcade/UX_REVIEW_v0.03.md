# Arcade v0.03 smoke checklist

## Snake Sprint

- Default speed feels clearly slower than the old build.
- SPEED control cycles Relaxed → Normal → Fast → Turbo → Relaxed.
- Speed cannot be changed after START.
- Swipe and arrow controls still work.
- Restart preserves the selected speed.
- Relaxed is the default on a fresh launch.

## Brick Breaker

- START is required.
- Tap and drag move the paddle.
- Ball bounces from walls and paddle.
- Brick hit removes one brick and adds 10 points.
- Missing the paddle consumes one life.
- Three misses end the run.
- Clearing all bricks ends as a win.
- MENU/help pause the simulation.

## Lane Dodge

- START is required.
- Tap and drag select among five lanes.
- Hazards descend and gradually become more demanding.
- Passed hazards increment score.
- Collision ends the run.
- Fixed-seed mode reproduces hazard lanes.
- MENU/help pause the simulation.
