# Music v0.2.0 changes

Adds a music-creation layer to the existing MethodMesh music utilities.

## New interactive creation capabilities

- `music.rhythm_capture` — tap rhythm inference and quantisation with raw timing retained.
- `music.drum_machine` — four-lane synthesized 16-step native beat maker.
- `music.beat_pads` — finger-drumming pads with captured hit timing.
- `music.live_looper` — microphone phrase loop with independent overdub layers, mute and undo.

## New algorithmic composition capabilities

- `music.euclidean_rhythm`
- `music.probability_pattern`
- `music.pattern_mutation`
- `music.chord_progression`
- `music.arpeggiator`
- `music.bassline`
- `music.melody_sequence`
- `music.motif_generator`
- `music.song_sketch`

## New dashboards

- `music.jam_dashboard` — persistent beat/rhythm scratchpad.
- `music.song_sketch_dashboard` — persistent harmony/rhythm/bass/melody/structure board.

All new methods remain **Development** pending target-repository and device validation.
