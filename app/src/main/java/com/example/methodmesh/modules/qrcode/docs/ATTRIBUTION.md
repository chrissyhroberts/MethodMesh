# Attribution

The barcode module uses the JourneyApps ZXing Android Embedded API for camera-based scanning and the ZXing encoding ecosystem for QR, Data Matrix, Aztec, PDF417 and supported 1D generation.

The current MethodMesh host resolves `com.journeyapps:zxing-android-embedded:4.3.0`; Android packaging remains owned by the host application. No remote barcode scanning or generation service is used.
