# Attribution

The AprilTag detection and pose-estimation concept is based on **AprilTag**, developed by the April Robotics Laboratory. Upstream project: `https://github.com/AprilRobotics/apriltag` and project information at `https://april.eecs.umich.edu/software/apriltag`.

The module uses AprilTag as a detector/pose backend but defines its own MethodMesh capability contracts, camera/ODK lifecycle, planar measurement transforms, trajectory summaries and experimental validity presentation.

No AprilTag source files or pre-generated tag artwork are copied into this module handoff.
