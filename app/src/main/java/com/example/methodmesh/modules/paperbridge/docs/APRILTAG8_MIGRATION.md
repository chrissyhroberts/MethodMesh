# Paper Bridge APRILTAG8 registration migration

Paper Bridge now uses `APRILTAG8` for newly authored paper schemas. Legacy `QR4` and `bullseye4` schemas remain readable.

## Geometry contract

- Family: AprilTag `tag36h11`.
- Marker IDs: `0..7`, assigned to `TL`, `TC`, `TR`, `LC`, `RC`, `BL`, `BC`, `BR`.
- The eight markers are generated by Paper Bridge in a dedicated white border outside the canonical form artwork.
- The canonical form is not rescaled when the border is generated, so existing ROI coordinates remain in the canonical artwork frame.
- Each detected marker contributes its four outer corners; a complete page therefore provides 32 source/destination correspondences.
- Registration fits one robust projective transform from the observed tag corners to the prepared-page canonical geometry, renders once, then crops the original canonical artwork rectangle.
- Field extraction occurs only after successful registration and uses saved canonical ROIs directly. Per-field geometric offsets are prohibited.

## Failure behaviour

Registration requires at least four unique markers with useful two-dimensional coverage (top, bottom, left and right represented). A clustered set of markers is rejected. The fitted transform must also pass RMS and maximum reprojection-error limits. Failure stops extraction rather than producing low-trust crops.

The extraction audit records marker count, correspondence count, RMS reprojection error, maximum reprojection error, quality and pass/fail state.

## Review crops

Analysis crops remain exact. Human review images use a modestly expanded display crop so the operator can see local context without adding surrounding print to OCR/OMR analysis.

## Compatibility

`QR4` and `bullseye4` registration paths are retained solely for existing schemas. Their historic anchor-centre coordinate frame is not applied to APRILTAG8 schemas. `PaperBridgeWorkspace.normalizeManifest` explicitly preserves `canonical_page` for APRILTAG8 manifests.

## Validation performed in this module package

- Generated blank and filled example prepared forms decode as all eight `tag36h11` IDs `0..7` with OpenCV's AprilTag dictionary.
- The bundled Kotlin image payloads are byte-for-byte identical to the example prepared-form PNGs and their embedded SHA-256 values.
- The module-local AprilTag registration source passes a targeted Kotlin compile against minimal Android graphics/model stubs.
- The package does not contain the host MethodMesh Gradle project, so a full Android/Compose build must be run after inserting this module into the host app.
