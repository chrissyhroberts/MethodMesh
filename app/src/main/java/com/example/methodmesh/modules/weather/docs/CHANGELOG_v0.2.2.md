# Weather v0.2.2 changes

- Replaced ambiguous numeric month-day chart labels such as `09-10 14h` with UK-style, unambiguous labels such as `10 Sep 14:00`.
- Next-days cards now use labels such as `Thu 10 Sep` rather than `09-10`.
- Time remains 24-hour throughout these compact dashboard labels.
- ISO-8601 remains available where it is an explicit data-entry/interchange format (for example Weather Snapshot timestamp entry); canonical method IDs, inputs, outputs and XLSForms are unchanged.
