# Weather v0.2.1 changes

- Changed the default radar zoom from `6.0` to `5.0` so radar opens at approximately national/whole-UK context on a typical phone-sized panel.
- Applied the same default to the dashboard, standalone radar capability, module setting metadata and native fallback.
- Explicit `input_zoom` remains supported and overrides the default.
- No canonical capability IDs, input names, output names, provider definitions or XLSForms changed.
