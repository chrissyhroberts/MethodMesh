Example XLSForms

The files below are the supplied, independently importable XLSForm examples. They are copied into this website unchanged.

Warning

An example demonstrates the current call shape; it is not automatically a validated production instrument. Review labels, identifiers, permissions, error handling and data-management requirements before study use.
