Spatial geometry

Status: Implemented with measurement constraints

This status is based on the supplied project documentation and example XLSForms. It is not a formal validation claim.

Purpose

Support tree-height, slope and distance-estimation workflows using device measurements and supplied distances.

Capability IDs

  • spatial_geometry

Requirements

  • Relevant onboard sensors.
  • A measured horizontal distance where required.
