Capability catalogue

Status vocabulary

  • Documented and demonstrated: source documentation and at least one corresponding XLSForm are present.
  • Implemented; XLSForm example pending: the supplied source documentation describes the capability, but no complete workbook was supplied.
  • Partial or constrained: the documentation identifies an important limitation, restricted scope or incomplete result path.
  • Experimental: useful for investigation, but not yet a stable study-facing interface.

Consistent page structure

Every capability page includes purpose, canonical IDs, requirements, screenshot placeholder, observed XLSForm calls, inputs, expected outputs, downloadable examples, implementation status, limitations and the detailed source reference.

Local device authentication

admin_fingerprint_confirmation

Documented and demonstrated

Request Android biometric or device-credential authentication and return a transient local-access decision.

Android app inspector

android_app_inspector

Experimental interoperability tool

Inspect installed Android packages and test intent-based integration contracts.

Signed event attestation

attestation.create, attestation.anchor_bundle

Documented and demonstrated

Create signed evidence that an event payload was attested using a selected local verification dependency, and anchor bundles of attestations.

Bluetooth device inspector

bluetooth_device_inspector

Documented and demonstrated

Discover Bluetooth devices and inspect GATT services, characteristics and values.

Bluetooth printer

bluetooth_print

Non-functional at present

Send supported print content to a configured Bluetooth printer.

Calibrated scale measurement

calibrated_scale

Documented and demonstrated

Collect a calibrated visual analogue or numeric range measurement using a physical line length.

Choice experiments

dce.pairwise, dce.maxdiff, dce.ranking, dce.points, dce.conjoint

Documented and demonstrated with some outstanding issues

Run interactive pairwise, MaxDiff, ranking, points-allocation and conjoint choice tasks.

Document scanner

document.scan

Implemented; XLSForm example pending

Capture document pages and return PDF and/or image outputs.

GPS target navigation

gps_target_navigator

Documented and demonstrated

Guide a user toward target coordinates using distance, bearing and an optional augmented-reality camera overlay.

ML Kit language translation

mlkit.translate

Implemented; XLSForm example pending

Translate text locally with ML Kit and manage downloaded language models.

ML Kit vision

mlkit.vision.analyze

Implemented; XLSForm example pending

Run supported ML Kit vision analyses on a selected image.

NFC capabilities

nfc_credential_provisioning, nfc_credential_verification, nfc_tag_read, nfc_tag_write, nfc_tag_wipe, protocol_nfc_check, protocol_nfc_complete

Documented and demonstrated

Read, write and wipe NFC tags; provision and verify credentials; and track protocol-step eligibility and completion.

ODK form launcher

odk_form_launcher

Documented and demonstrated

Open a selected ODK Collect form and return the matched form, project, instance and launch status.

External command library

provider.command.run

Partial return support

Run a saved, typed Android intent command against an installed provider application.

Automatic code scanner

qr.scan

Documented and demonstrated

Scan QR codes and supported barcode formats and return the decoded payload and detected format.

Question primitives

question.text, question.number, question.select_one, question.select_multiple

Implemented; native protocol building block

Capture simple text, numeric, single-choice and multiple-choice answers directly inside MethodMesh protocols.

Random number generator

random.number.generate

Documented and implemented

Generate secure or fixed-seed random numbers with count, range and step controls.

Scaled photo selector

scaled_photo.capture

Documented and demonstrated

Capture a ruler-calibrated photograph, select grid regions, and return original and annotated image attachments.

Image redaction

image.redact

Implemented and documented

Capture or pick an image, mask selected grid cells, and return only the redacted image plus mask metadata.

Scheduler

scheduler

Implemented with evolving target support

Create and transfer local recurring schedules for forms, web targets and future MethodMesh process targets.

ESP32 sensor firmware installer

sensor_firmware_installer

Current scope limited to ESP32-C3

Install bundled MethodMesh sensor firmware onto a supported ESP32-C3 device over USB.

BLE sensor-node provisioner

sensor_node_provisioner

Implemented; XLSForm example pending

Write identity and sampling configuration to a compatible MethodMesh BLE sensor node and register it locally.

Read sensor

sensor.read

Documented and demonstrated

Read, trace, average or discover registered MethodMesh BLE sensor nodes.

Send SMS

sms.send

Send accepted; delivery confirmation pending

Send an SMS directly from MethodMesh and return the local send-request status.

Spatial geometry

spatial_geometry

Implemented with measurement constraints

Support tree-height, slope and distance-estimation workflows using device measurements and supplied distances.

Speech transcription

speech.transcribe

Implemented; XLSForm example pending

Capture speech and return a transcription with provider metadata.

SVG polygon selector

svg.select

Documented and demonstrated

Display an SVG and return selected polygon or region identifiers.
