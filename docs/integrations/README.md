# Cross-system integration specifications

These documents describe systems that integrate MethodMesh with other products. They are preserved design inputs, not additional MethodMesh-wide authorities. MethodMesh implementation contracts remain governed by [Master Book v1.25](../METHODMESH_MASTER_BOOK.md).

The Trial Platform specification is an implementation candidate, as stated in its own status, and is not a claim of a validated production clinical-trial system.
