Forms

Cryptographic checkpoint

BUNDLE SELF-CHECKED BEFORE PACKAGING

The completed ZIP is only produced after MethodMesh's checksum, Merkle, checkpoint and RFC3161 checks pass. A routine auditor does not need to run a command.

Technical: independently verify this bundle

An independent technical reviewer can repeat the cryptographic checks locally without Central credentials.

Where to run it: first extract the ZIP, then open a terminal in the extracted bundle root — the same directory that contains index.html, system.html, and verify_bundle.py.

python3 ./verify_bundle.py

Or, from another working directory, give Python the relative or absolute path to the extracted bundle:

python3 ./path/to/extracted-bundle/verify_bundle.py

The verifier resolves the TSA and trust files relative to its own location, so it does not matter where your terminal's current working directory is when you use the second form.

No participant answers, old/new research values, XML, photographs or attachment bytes are rendered by this dashboard.
